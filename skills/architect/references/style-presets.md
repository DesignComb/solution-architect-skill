# 風格預設集（讓產品不要長出「AI 味」）

AI 沒被指定風格時，會長出同一張臉：紫藍漸層、白底圓角卡、Inter 字體、
置中大標＋兩顆按鈕＋三欄功能卡。這不是醜，是**「沒有人做過決定」的樣子**。
所以訪談階段 1 要讓使用者三選一（用 AskUserQuestion，**描述感覺、不丟元件庫名字**），
階段 3 把選定風格的完整規格寫進建議書，開工時整段交給實作的 AI。

## 訪談時怎麼問（階段 1 用）

「你希望它給人什麼感覺？」三個選項照使用者的形態給預設推薦（放第一個）：

| 選項（給使用者看的描述） | 內部代號 | 預設推薦給 |
|--------------------------|----------|------------|
| **俐落**——乾淨、專業，像一個好用的工具 | clean | 管理系統、內部工具、後台 |
| **雜誌**——有質感、像一本刊物或品牌型錄 | editorial | 內容展示、官網、作品集 |
| **溫暖**——圓潤、親切、有生活感 | warm | 社群、親子、餐飲、生活服務 |

使用者用 Other 描述其他感覺（「像精品」「像遊戲」）也可以——記下形容詞，
沿用最接近的一套當基底再調整。答案寫進 `01-requirements.md` 的「外觀方向」。

## A. 俐落（clean）

- **字體**：無襯線系統字；中文 Noto Sans TC / PingFang TC；標題只靠字重與大小分層，不加花樣
- **色彩**：中性灰階打底（近白底、近黑字）＋**一個**強調色（請使用者挑一個喜歡的顏色當品牌色）
- **形狀**：小圓角（6–8px）、1px 細邊框、陰影極輕或不用
- **密度**：資訊可以密，但對齊要嚴格；表格、清單是主角
- **元件庫**：shadcn/ui（React）或 shadcn-vue；Tailwind CSS
- **禁**：漸層、五顏六色的圖示、彩色大色塊

## B. 雜誌（editorial）

- **字體**：襯線標題（Noto Serif TC；英文 Georgia 系）× 無襯線內文；標題大膽放大、行距鬆
- **色彩**：紙感底色（暖白、米色）、墨色文字、**一個**飽和強調色（磚紅、深綠這類印刷感的顏色）
- **形狀**：直角或極小圓角；用**細分隔線與留白**做區隔，不要滿版卡片格
- **密度**：留白就是設計；一屏只講一件事
- **元件庫**：Tailwind CSS 自組（＋ Typography 外掛排文章）；通常不需要元件庫
- **禁**：彩色漸層、圓角卡片牆、置中三欄功能區

## C. 溫暖（warm）

- **字體**：無襯線但字重活潑（標題 700 以上）；中文 Noto Sans TC，標題可用圓體感字型
- **色彩**：奶油或暖白底＋2–3 個低飽和暖色（蜜桃、薄荷、奶茶）；文字用深棕/深綠，**不用純黑**
- **形狀**：大圓角（14–20px）、實色塊、柔和陰影；可愛但不幼稚（不要貼滿表情符號）
- **密度**：寬鬆、大按鈕、大點擊區——長輩與小孩也好按
- **元件庫**：DaisyUI 或 Tailwind CSS 自組
- **禁**：企業灰、細線框、高冷的極簡

## 通用反 AI 味清單（無論選哪套，寫進建議書）

1. 不用紫→藍漸層當主視覺。
2. 不用 Inter/Roboto 當唯一字體；**中文內容必須指定中文字體**，不能只寫英文字體名。
3. 首頁不要「置中大標＋兩顆按鈕＋三欄卡片」的預設排法——至少換一種構圖（左右不對稱、雜誌式、清單式）。
4. 圖示只用一套、單色，跟著強調色走。
5. 空狀態、載入中、錯誤畫面也要跟著同一套風格。
6. 把選定風格的**整段規格**連同需求交給實作的 AI，並明說「避免通用 AI 模板臉」。
